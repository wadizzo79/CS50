# CS50 Problem Sets

This repository contains my solutions to programming assignments and practice problems completed as part of **Harvard University's CS50: Introduction to Computer Science**.

The work in this repository reflects my learning progress through the course and follows the structure of CS50 problem sets.

## Purpose
The purpose of this repository is to:
- Practice core computer science concepts taught in CS50
- Improve problem-solving and algorithmic thinking
- Gain hands-on experience with C, Python, and basic web technologies

## Topics Covered
Across the assignments, the following concepts are explored:
- C programming fundamentals
- Algorithms and problem-solving
- Arrays, strings, and memory management
- Data structures
- File I/O
- Python basics
- Debugging and testing

## Repository Structure
Each folder corresponds to a specific CS50 problem or lab.

Examples:
- `caesar/` – Caesar cipher encryption
- `cash/` – Greedy algorithms
- `credit/` – Credit card validation
- `dna/` – DNA sequence matching
- `mario-less/` and `mario-more/` – Pattern printing exercises
- `readability/` – Text readability analysis
- `filter-less/` – Image filtering basics
- `data_structures/` – Data structure practice
- `python/` – Python-based CS50 exercises

The structure generally follows the CS50 weekly problem sets.

## Notes
- Solutions may not represent the most optimized or production-ready implementations.
- Some problems may have multiple valid approaches.
